# ParcelVox logo

The mark is a parcel-shaped speech bubble carrying a voice waveform — the
product in one image: a parcel that talks. It uses the brand palette
(navy `#0C1623`, cyan `#35BFE3`) and pairs with the wordmark in Saira
Semi Condensed Bold, `.AI` accented in cyan (`#1E8FB0` on light backgrounds
for contrast). All text in the SVGs is converted to paths, so no fonts are
needed to render them.

| File | Use |
| --- | --- |
| `parcelvox-logo-dark.svg` | Full lockup on dark backgrounds |
| `parcelvox-logo-light.svg` | Full lockup on light backgrounds |
| `parcelvox-mark.svg` | Mark only (cyan bubble) — avatars, favicons, dark surfaces |
| `parcelvox-mark-navy.svg` | Mark only (navy bubble) — light surfaces |
| `parcelvox-mark-512.png` | 512px transparent PNG export of the mark |

Keep clear space around the lockup of at least the mark's width, and don't
recolor outside the palette. The mark stays legible down to 16px.
